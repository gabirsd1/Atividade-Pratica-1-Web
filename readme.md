# ☁️ Nuvem Jump

**Nuvem Jump** é um jogo interativo de plataforma vertical desenvolvido para a disciplina de Programação Web. O objetivo é guiar o personagem pelas alturas, saltando entre nuvens em um cenário que muda conforme o passar do dia, acumulando pontos e evitando a queda.

---

**Tecnologias Utilizadas**
* **HTML5:** Estruturação da página e do Canvas.
* **CSS3:** Estilização responsiva, interface (efeito Glassmorphism) e design dinâmico.
* **JavaScript Vanilla:** Física do jogo, sistema de fases, movimentação e partículas, desenvolvido sem o uso de frameworks externos.

**Como Jogar**
* Acesse o link da versão jogável hospedada no **GitHub Pages**.
* Utilize as **Setas do Teclado (← e →)** para movimentar o personagem para os lados.
* Pule estrategicamente pelas nuvens (fique atento, pois algumas começam a se mover nas fases avançadas!).
* Alcance **1000 pontos** para zerar o desafio.
