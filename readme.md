# Nuvem Jump

Um jogo de plataforma vertical desenvolvido para a disciplina de Programação Web. O objetivo é saltar de plataforma em plataforma, subindo o máximo possível sem cair, acumulando pontos.

## Tecnologias
* HTML5
* CSS3
* JavaScript Vanilla (sem frameworks)

## Instruções
Acesse o link do GitHub Pages. Utilize as **Setas do teclado (Esquerda e Direita)** para movimentar o personagem.
